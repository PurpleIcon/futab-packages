FuTab packages

The apt, dnf and Flatpak repositories of FuTab, a free guitar tablature and score viewer, editor and player, and of its own plugins. Each package is the one attached to the release of its own repository; this site only signs and lists them.

FuTab's other plugins (Guitar Pro, MIDI, ALSA, PipeWire and more) are OxiGuitar's, from OxiGuitar's repositories: add those too, as below. Never install the oxiguitar app itself beside FuTab.

Debian, Ubuntu and relatives (apt)

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL @URL@/futab.gpg -o /etc/apt/keyrings/futab.gpg
sudo curl -fsSL @URL@/futab.sources -o /etc/apt/sources.list.d/futab.sources
sudo curl -fsSL https://mateusrdp.github.io/oxiguitar-packages/oxiguitar.gpg -o /etc/apt/keyrings/oxiguitar.gpg
sudo curl -fsSL https://mateusrdp.github.io/oxiguitar-packages/oxiguitar.sources -o /etc/apt/sources.list.d/oxiguitar.sources
sudo apt update
sudo apt install futab

futab recommends the Guitar Pro, MIDI, ALSA and PipeWire plugins, which apt installs with it from OxiGuitar's repository; only on a desktop without Wayland, install futab-x11 instead (the X11 build, deprecated; it replaces futab). apt upgrade keeps all of them current.

Fedora and relatives (dnf)

sudo curl -fsSL @URL@/futab.repo -o /etc/yum.repos.d/futab.repo
sudo curl -fsSL https://mateusrdp.github.io/oxiguitar-packages/oxiguitar.repo -o /etc/yum.repos.d/oxiguitar.repo
sudo dnf install futab

Any Linux (Flatpak)

flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --if-not-exists futab @URL@/flatpak/futab.flatpakrepo
flatpak remote-add --if-not-exists oxiguitar https://mateusrdp.github.io/oxiguitar-packages/flatpak/oxiguitar.flatpakrepo
flatpak install futab io.github.purpleicon.FuTab
flatpak install oxiguitar io.github.mateusrdp.OxiGuitar.Plugin.guitarpro io.github.mateusrdp.OxiGuitar.Plugin.midi io.github.mateusrdp.OxiGuitar.Plugin.pipewire

Or open io.github.purpleicon.FuTab.flatpakref in a software centre, then add OxiGuitar's repository for the plugins. The runtime comes from Flathub. flatpak update keeps all of them current.

The signing key

All three repositories are signed with one key, fingerprint @FINGERPRINT@: futab.asc (armoured) or futab.gpg (binary). Check the fingerprint against the one in the repository's README. OxiGuitar's repositories have their own key, trusted only for them.

FuTab itself never downloads anything from here: only apt, dnf and Flatpak do, when you ask them. The packages in this build are listed in packages.txt.
